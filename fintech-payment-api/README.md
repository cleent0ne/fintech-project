# Fintech Payment API

A Spring Boot based API for processing payments and managing fintech operations.

## Features
- Payment Processing
- Account Management
- Transaction Logging
- Secure API Endpoints

## Getting Started

### Prerequisites
- JDK 17
- Maven 3.8+
- Docker (optional)

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Build the project:
   ```bash
   mvn clean install
   ```
3. Run the application:
   ```bash
   mvn spring-boot:run
   ```

### Docker
To run with Docker:
```bash
docker-compose up --build
```
